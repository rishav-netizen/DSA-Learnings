1. WHAT IS ASCII?
-----------------
- ASCII stands for: "American Standard Code for Information Interchange"
- It is a character encoding standard that assigns a unique numeric code (integer)
  to characters, numbers, punctuation marks, and control codes.
- Standard ASCII uses 7 bits to represent each character.
- Total number of standard ASCII codes = 2^7 = 128 codes (ranging from 0 to 127).
- In C/C++, a `char` data type occupies 1 Byte (8 bits):
    * Signed char:   -128 to 127
    * Unsigned char:    0 to 255 (includes Extended ASCII: 128 to 255)

3. CATEGORIZATION OF ASCII CHARACTERS
================================================================================

A. Non-Printable / Control Characters (Codes: 0 to 31, and 127)
   Used for device control, data stream signaling, and text formatting.
   Key control characters:
     -   0 : '\0'  NUL (Null character / String terminator)
     -   7 : '\a'  BEL (Bell / Alert)
     -   8 : '\b'  BS  (Backspace)
     -   9 : '\t'  HT  (Horizontal Tab)
     -  10 : '\n'  NL/LF (New Line / Line Feed)
     -  11 : '\v'  VT  (Vertical Tab)
     -  12 : '\f'  NP/FF (New Page / Form Feed)
     -  13 : '\r'  CR  (Carriage Return)
     -  27 : '\e'  ESC (Escape)
     - 127 :       DEL (Delete)

B. Printable Characters (Codes: 32 to 126) — Total: 95 characters
   1. Space:
      - 32 : ' '   SP  (Space character)

   2. Digits ('0' - '9'):
      - 48 to 57  (10 characters: '0'=48, '1'=49, ..., '9'=57)

   3. Uppercase Letters ('A' - 'Z'):
      - 65 to 90  (26 characters: 'A'=65, 'B'=66, ..., 'Z'=90)

   4. Lowercase Letters ('a' - 'z'):
      - 97 to 122 (26 characters: 'a'=97, 'b'=98, ..., 'z'=122)

   5. Special & Punctuation Characters:
      - 33 to 47   :  ! " # $ % & ' ( ) * + , - . /
      - 58 to 64   :  : ; < = > ? @
      - 91 to 96   :  [ \ ] ^ _ `
      - 123 to 126 :  { | } ~

4. MUST-KNOW RULES & FORMULAS FOR DSA / PROGRAMMING
================================================================================

1. Case Conversion & Difference:
   - Difference between uppercase and lowercase letters is exactly 32:
       'a' - 'A' = 97 - 65 = 32
       'b' - 'B' = 98 - 66 = 32
   
   - Uppercase -> Lowercase:
       char lower = upper + 32;          // e.g., 'A' + 32 = 'a'
       char lower = upper + ('a' - 'A'); // portable way
       char lower = upper | 32;          // bitwise OR (sets 5th bit)
       char lower = upper | ' ';

   - Lowercase -> Uppercase:
       char upper = lower - 32;          // e.g., 'a' - 32 = 'A'
       char upper = lower - ('a' - 'A'); // portable way
       char upper = lower & ~32;         // bitwise AND (clears 5th bit)
       char upper = lower & '_';

   - Toggle Case:
       char toggled = ch ^ 32;           // bitwise XOR
       char toggled = ch ^ ' ';

2. Character to Integer (Digit Conversion):
   - To convert numeric char to integer:
       int digit = ch - '0';             // e.g., '5' - '0' = 53 - 48 = 5
   - To convert integer (0-9) to numeric char:
       char ch = digit + '0';            // e.g., 5 + '0' = 5 + 48 = 53 ('5')

3. Array Index Mapping (for Hashing / Frequency Arrays / Bitmasking):
   - Uppercase index (0 to 25):
       int index = ch - 'A';             // 'A' -> 0, 'B' -> 1, ..., 'Z' -> 25
   - Lowercase index (0 to 25):
       int index = ch - 'a';             // 'a' -> 0, 'b' -> 1, ..., 'z' -> 25

4. Checking Character Types:
   - Is Uppercase: (ch >= 65 && ch <= 90)   OR (ch >= 'A' && ch <= 'Z')
   - Is Lowercase: (ch >= 97 && ch <= 122)  OR (ch >= 'a' && ch <= 'z')
   - Is Alphabet:  (isUpper || isLower)
   - Is Digit:     (ch >= 48 && ch <= 57)   OR (ch >= '0' && ch <= '9')

5. CHARACTERS VS STRINGS IN C / C++
================================================================================

1. Character Variable:
   - Stores a single character enclosed in single quotes.
   - Takes 1 Byte of memory.
   - Example:
       char temp = 'A';   // ASCII code 65 stored in 1 byte

2. Character Array:
   - Collection of characters in contiguous memory.
   - Example:
       char arr[5] = {'A', 'B', 'C', 'D', 'E'}; // Array of 5 chars, NOT a string

3. String:
   - A character array TERMINATED by a Null Character ('\0').
   - The null character '\0' has ASCII value 0 (NUL).
   - Also known as: String delimiter / String terminator / Sentinel character.
   - It signals functions (like printf, strlen, cout) where the string ends.
   - Example:
       char name[5] = {'J', 'o', 'h', 'n', '\0'}; // Valid string of length 4
       char name[]  = "John";                     // Automatically appends '\0'
                                                  // Size in memory = 5 bytes
                                                  // Length of string = 4

4. Key Distinction:
   - '0'   -> Character zero (ASCII code 48)
   - 0     -> Integer zero (4 bytes)
   - '\0'  -> Null character (ASCII code 0, 1 byte)
   - NULL  -> Null pointer constant ((void*)0)


================================================================================
6. ASCII vs EXTENDED ASCII vs UNICODE
================================================================================

- Standard ASCII : 7 bits  -> 128 characters (0 to 127)
- Extended ASCII : 8 bits  -> 256 characters (0 to 255), adds graphical/accent symbols
- UNICODE        : 16/32 bits or variable-width (UTF-8, UTF-16, UTF-32)
                   Supports all world languages (Chinese, Japanese, Hindi, Arabic,
                   emojis, math symbols, etc.). UTF-8 is backward-compatible with ASCII.
