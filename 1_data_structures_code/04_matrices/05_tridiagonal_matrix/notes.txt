Tridiagonal Matrix
==================

Definition:
- A square matrix (n x n) where non-zero elements are confined only to three diagonals:
  1. Main diagonal (i - j = 0) -> n elements
  2. Lower sub-diagonal (i - j = 1) -> n - 1 elements
  3. Upper super-diagonal (i - j = -1 or j - i = 1) -> n - 1 elements
- Condition: A[i][j] = 0 when |i - j| > 1.

Key Properties:
- Total non-zero elements: (n - 1) + n + (n - 1) = 3n - 2.
- Total zero elements: n^2 - (3n - 2).

Storage Optimization:
- Store all non-zero elements in a single 1D array of size 3n - 2.

Mapping Formulas:

1. 1-Based Matrix Indexing (as used in C++ implementation, 1 <= i, j <= n):
   - Lower sub-diagonal (i - j = 1):
     Index = i - 2
   - Main diagonal (i - j = 0):
     Index = (n - 1) + (i - 1)
   - Upper super-diagonal (i - j = -1):
     Index = (2n - 1) + (i - 1)

2. 0-Based Matrix Indexing (0 <= i, j < n):
   - Lower sub-diagonal (i - j = 1):
     Index = i - 1
   - Main diagonal (i - j = 0):
     Index = (n - 1) + i
   - Upper super-diagonal (i - j = -1):
     Index = (2n - 1) + i

Complexity:
- Space Complexity: O(3n - 2) -> O(n) instead of O(n^2)
- Time Complexity for Get/Set: O(1)
- Display: O(n^2)
