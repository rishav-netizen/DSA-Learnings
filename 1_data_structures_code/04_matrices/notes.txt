=========================================
Special Matrices & Square Matrix Context
=========================================

The image lists 8 types of Special Matrices studied in Data Structures & Algorithms (DSA):

1. Diagonal Matrix
2. Lower Triangular Matrix
3. Upper Triangular Matrix
4. Symmetric Matrix
5. Tridiagonal Matrix
6. Band Matrix
7. Toeplitz Matrix
8. Sparse Matrix

-----------------------------------------
Types of Special Matrices Explained:
-----------------------------------------

1. Diagonal Matrix:
   - A matrix where all non-diagonal elements are zero.
   - A[i][j] = 0 when i != j.

2. Lower Triangular Matrix:
   - A matrix where all elements above the main diagonal are zero.
   - A[i][j] = 0 when i < j. Non-zero elements exist only where i >= j.

3. Upper Triangular Matrix:
   - A matrix where all elements below the main diagonal are zero.
   - A[i][j] = 0 when i > j. Non-zero elements exist only where i <= j.

4. Symmetric Matrix:
   - A matrix that is equal to its transpose (A[i][j] = A[j][i]).
   - The element at row i, column j is identical to the element at row j, column i.

5. Tridiagonal Matrix:
   - A matrix where non-zero elements are confined only to the main diagonal, the sub-diagonal (just below the main diagonal), and the super-diagonal (just above the main diagonal).
   - A[i][j] = 0 when |i - j| > 1.

6. Band Matrix:
   - A matrix where non-zero elements are restricted within a diagonal "band" around the main diagonal bounded by lower and upper bandwidths.
   - A[i][j] = 0 when |i - j| > k (where k is the band half-width).

7. Toeplitz Matrix:
   - A matrix in which every descending diagonal from left to right contains identical elements.
   - A[i][j] = A[i-1][j-1].

8. Sparse Matrix:
   - A matrix containing a majority of zero elements. Specialized representations (e.g., 3-column element list, CSR format) are used to store only non-zero elements.

-----------------------------------------
How They Are Square Matrices:
-----------------------------------------

In Data Structures & Algorithms (DSA), these special matrices are primarily studied as Square Matrices (number of rows = number of columns, i.e., n x n) for the following reasons:

1. Main Diagonal Reliance:
   - Conceptually, Diagonal, Lower Triangular, Upper Triangular, Tridiagonal, and Band matrices are defined relative to the main diagonal (where row index i == column index j). A main diagonal that strictly connects the top-left corner (0,0) to the bottom-right corner (n-1, n-1) and splits the matrix symmetrically requires an n x n square structure.

2. Matrix Symmetry (Transpose Requirement):
   - A Symmetric Matrix satisfies A = A^T. Transposing an m x n matrix changes its dimensions to n x m. Thus, equality is only possible if m = n (i.e., the matrix is square).

3. Compact 1D Array Storage & Indexing Formulas:
   - For n x n square matrices with structured zero elements, we can map non-zero elements to a 1D array of size smaller than n^2 using row-major or column-major mapping formulas.

4. Applicability to Toeplitz & Sparse Matrices:
   - While Toeplitz and Sparse matrices can theoretically be rectangular (m x n), Toeplitz matrices in DSA square matrix optimization problems are typically studied as n x n, whereas Sparse matrices can be either square or rectangular.
